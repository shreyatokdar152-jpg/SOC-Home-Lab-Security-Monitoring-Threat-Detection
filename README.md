# SOC-Home-Lab-Security-Monitoring-Threat-Detection
A hands-on SOC home lab using Wazuh SIEM for security monitoring, log analysis, threat detection, alerting, and incident investigation.
his project focuses on building a practical Security Operations Center (SOC) Home Lab for security monitoring, log analysis, threat detection, alert generation, and basic incident investigation using Wazuh SIEM.

The lab simulates a small enterprise security environment using virtual machines running Ubuntu 22.04 Desktop and Windows, with Wazuh deployed as the central security monitoring platform.

The objective of this project is to gain hands-on experience with real-world SOC activities, including endpoint monitoring, centralized log collection, detection rule creation, alert investigation, and security event analysis.
