# SOC Home Lab – Network Architecture

## Overview

The SOC Home Lab is designed to simulate a small enterprise security monitoring environment using **Wazuh SIEM**, **Ubuntu 22.04**, **Windows**, and **VirtualBox**.

The architecture provides a controlled environment where security events generated by Windows and Linux endpoints can be collected, analyzed, detected, and investigated through the Wazuh platform.

The main objective of this architecture is to demonstrate how a SOC analyst can monitor multiple endpoints from a centralized SIEM platform.

## Components

### 1. Windows Host

The physical Windows computer acts as the host machine for the virtual lab.

**Responsibilities:**

* Runs VirtualBox
* Hosts the virtual machines
* Provides hardware resources such as CPU, RAM, and storage
* Provides Internet connectivity to the virtual environment

---

### 2. Ubuntu 22.04 – Wazuh Server

Ubuntu 22.04 is used as the central security monitoring server.

The Wazuh environment includes:

* **Wazuh Manager** – Receives and analyzes security events.
* **Wazuh Indexer** – Stores and indexes security events.
* **Wazuh Dashboard** – Provides visualization and security monitoring.

Example IP:

```text
192.168.56.101
```

---

### 3. Windows VM – Wazuh Agent

The Windows virtual machine acts as a monitored endpoint.

The Wazuh Agent collects security-related events such as:

* Windows Security Events
* Authentication events
* Process activity
* PowerShell activity
* User account activity
* File changes

Example IP:

```text
192.168.56.102
```

---

### 4. Ubuntu VM – Wazuh Agent

A separate Ubuntu virtual machine is used as a Linux endpoint.

The Wazuh Agent can collect:

* Authentication logs
* SSH events
* System logs
* Sudo activity
* File integrity events
* Other security-related Linux events

Example IP:

```text
192.168.56.103
```

## Example Detection Scenario

A controlled brute-force login scenario can be used to test the architecture.

### Step 1 – Generate Security Event

Multiple failed login attempts are generated on the Windows endpoint.

### Step 2 – Log Collection

The Windows Wazuh Agent collects the relevant security events.

### Step 3 – Event Forwarding

The events are sent to the Wazuh Manager.

### Step 4 – Detection

Wazuh analyzes the events using its decoders and detection rules.

### Step 5 – Alert Generation

If the event matches the configured detection condition, Wazuh generates an alert.

### Step 6 – Investigation

The SOC analyst views the alert in the Wazuh Dashboard and investigates:

* Source IP
* Username
* Timestamp
* Event ID
* Number of attempts
* Related events

## Summary

This network architecture provides a controlled and isolated environment for learning and demonstrating **SOC operations using Wazuh**. Windows and Ubuntu endpoints generate security events, Wazuh agents collect the events, and the Wazuh server analyzes and visualizes them through the dashboard.

The architecture forms the foundation of the **SOC Home Lab – Security Monitoring & Threat Detection** project and can be expanded as additional detection and investigation use cases are developed.
